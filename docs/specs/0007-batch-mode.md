# 0007. Пакетная обработка папки

- **Статус:** Implemented
- **Дата:** 2026-11-11
- **Тип:** ретроспективная спека (восстановлена по коммиту)
- **Коммит:** `210a94a` — `package mode`
- **Связанные спеки:** 0005, 0008, 0009
- **Затрагиваемые файлы:** `main.py`, `tests/test_batch.py`, `README.md`

## Контекст и проблема

До этого утилита обрабатывала один файл за запуск. Для папки с несколькими
главами приходилось запускать её многократно, и каждый раз заново
загружалась модель. Нужен режим, который обрабатывает все Markdown-файлы
папки за один запуск.

## Цели и не-цели

**Цели:**

- обработать все `.md`/`.markdown` верхнего уровня указанной папки;
- загрузить модель один раз на всю пачку;
- сохранять результаты рядом с исходниками;
- не прерывать пачку из-за ошибки в одном файле;
- показывать прогресс и итог.

**Не-цели:**

- рекурсивный обход вложенных папок (появится отдельным режимом в 0001);
- своя выходная папка для пачки;
- параллельная обработка файлов.

## Пользовательский сценарий

```bash
python main.py ~/Documents/notes --batch
python main.py ~/Documents/notes --batch --voice masha --no-mp3
```

В конце печатается «Обработано файлов: N из M».

## Требования

- **FR-1.** Флаг `-b`/`--batch` включает пакетный режим.
- **FR-2.** В пакетном режиме позиционный аргумент должен быть существующей
  папкой; файл или отсутствующий путь — ошибка, код 1.
- **FR-3.** Собираются `.md` и `.markdown` верхнего уровня, без рекурсии,
  в отсортированном по имени порядке.
- **FR-4.** Если Markdown-файлов нет, печатается сообщение и код 1.
- **FR-5.** `-o/--output` вместе с `--batch` запрещён: результаты пишутся
  рядом с исходниками.
- **FR-6.** Модель загружается один раз до цикла по файлам.
- **FR-7.** Ошибка в одном файле печатается, но не прерывает остальные;
  итоговый код 1, если были сбои.
- **FR-8.** Для каждого файла печатается заголовок `[i/N] путь`, прогресс
  содержит имя файла.
- **FR-9.** Аудио и временный `.txt` сохраняются рядом с исходным `.md`.

## Критерии приёмки

- **AC-1.** Дано папка с `a.md`, `b.markdown`, `note.txt` и вложенным
  `sub/nested.md`, когда включён пакетный режим, тогда обрабатываются `a.md`
  и `b.markdown`, вложенный файл игнорируется.
- **AC-2.** Дано пустая папка, когда включён пакетный режим, тогда печатается
  «В папке нет Markdown-файлов» и код 1.
- **AC-3.** Дано файл вместо папки, когда передан `--batch`, тогда печатается
  ошибка и код 1.
- **AC-4.** Дано `--batch` и `-o`, когда запускается CLI, тогда печатается
  запрет и код 1.
- **AC-5.** Дано несколько файлов, когда один из них падает, тогда остальные
  обрабатываются, итог содержит число успешных.
- **AC-6.** Дано пакетный режим, когда синтез завершён, тогда `.mp3`/`.wav`
  лежат рядом с каждым исходником.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| Один файл битый | Остальные обрабатываются, код 1 |
| Пустая папка | Сообщение, код 1 |
| Нет папки | Сообщение, код 1 |
| Вложенные `.md` | Игнорируются |
| Файл без прав на запись | Ошибка по файлу, пачка продолжается |
| `-o` с папкой | Запрет, код 1 |

## Решения и альтернативы

- **Решение:** отдельный флаг `--batch` вместо автоматического определения.
  **Почему:** на этом этапе режим был явным; позже его заменил один аргумент
  (спека 0009).
- **Решение:** сохранять аудио рядом с исходниками.
  **Почему:** иначе файлы из разных папок смешивались бы в одной выходной.
- **Решение:** ловить исключения по каждому файлу.
  **Почему:** одна ошибка не должна отменять всю пачку.
