# 0006. Голос `dima` по умолчанию

- **Статус:** Implemented
- **Дата:** 2026-11-11
- **Тип:** ретроспективная спека (восстановлена по коммиту)
- **Коммит:** `d3acb64` — `fixed model download`
- **Связанные спеки:** 0002, 0005
- **Затрагиваемые файлы:** `main.py`, `kokoro_tts/config.py`

## Контекст и проблема

В первой версии голосом по умолчанию был `masha`. Коммит `d3acb64` заменил
его на `dima` одновременно с другими изменениями загрузки модели. Причина
выбора `dima` в истории коммита не зафиксирована; спека фиксирует само
поведение, чтобы оно не потерялось.

## Цели и не-цели

**Цели:**

- сделать `dima` голосом по умолчанию и в CLI, и в `Settings`;
- сохранить возможность явно выбрать любой голос из `VOICES`.

**Не-цели:**

- удаление или переименование голосов;
- изменение качества или параметров конкретного голоса.

## Пользовательский сценарий

```bash
python main.py input/example.md              # голос dima
python main.py input/example.md --voice masha
python main.py input/example.md --voice sveta
```

## Требования

- **FR-1.** `Settings.voice` по умолчанию — `dima`.
- **FR-2.** Аргумент `--voice` по умолчанию — `dima`.
- **FR-3.** Явно переданный `--voice` переопределяет значение по умолчанию.
- **FR-4.** Список доступных голосов остаётся `sveta`, `masha`, `dima`.

## Критерии приёмки

- **AC-1.** Дано запуск без `--voice`, когда создаётся `Settings`, тогда
  `voice == "dima"`.
- **AC-2.** Дано `--voice masha`, когда разбираются аргументы, тогда
  `args.voice == "masha"`.
- **AC-3.** Дано неизвестный голос, когда запускается CLI, тогда argparse
  выдаёт ошибку выбора.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| `--voice` не указан | Используется `dima` |
| `--voice masha` | Используется `masha` |
| `--voice unknown` | Ошибка argparse, код 2 |

## Решения и альтернативы

- **Решение:** `dima` по умолчанию.
  **Почему:** зафиксировано коммитом; содержательная причина в истории
  отсутствует.
- **Альтернатива:** оставить `masha`.
  **Почему отвергнута:** противоречит принятому поведению.

## Влияние

- `main.py` и `config.py` синхронизированы по значению по умолчанию.
- README и примеры обновлены на `dima`.
- Обратная совместимость: поведение без флага меняется, но явный `--voice`
  работает как раньше.
