# 0003. Локальная папка модели `model/`

- **Статус:** Implemented
- **Дата:** 2026-11-11
- **Тип:** ретроспективная спека (восстановлена по коммиту)
- **Коммит:** `7b26c09` — `fixed model place problem`
- **Связанные спеки:** 0002, 0004
- **Затрагиваемые файлы:** `kokoro_tts/synthesizer.py`, `.gitignore`

## Контекст и проблема

При скачивании в кэш Hugging Face файлы репозитория модели лежат в виде
символических ссылок на `blobs/`. `ru_g2p.py` ожидает рядом с собой папку
`espeak-data` и не находит её через такую структуру, из-за чего русская
фонетика не работает.

Нужно хранить репозиторий модели в обычной предсказуемой папке проекта,
чтобы рядом с `ru_g2p.py` лежали все нужные данные.

## Цели и не-цели

**Цели:**

- скачивать модель в `model/` в корне проекта;
- сохранить работоспособность `ru_g2p.py` и `espeak-data`;
- не скачивать лишние форматы и чужие чекпоинты.

**Не-цели:**

- повторные запуски без сети (следующая спека 0004);
- выбор произвольной папки модели через CLI;
- проверка контрольных сумм файлов.

## Пользовательский сценарий

```bash
python main.py input/example.md
# при первом запуске модель скачивается в ./model/
# ru_g2p.py находит ./model/espeak-data и синтез работает
```

## Требования

- **FR-1.** Путь модели — `MODEL_DIR = <корень проекта>/model`, а не кэш
  Hugging Face.
- **FR-2.** `snapshot_download` вызывается с `local_dir=MODEL_DIR`.
- **FR-3.** Из репозитория исключаются `onnx/*`, `voices/*.bin`, `*.wav`,
  `*.mp3`, `*.png`, `*.jpg` и чужие чекпоинты (все, кроме выбранного голоса).
- **FR-4.** `ru_g2p.py` импортируется из `MODEL_DIR` через `sys.path`, чтобы
  рядом нашлась папка `espeak-data`.
- **FR-5.** `model/` не попадает в git.

## Критерии приёмки

- **AC-1.** Дано чистый клон без `model/`, когда запускается синтез, тогда
  файлы модели появляются в `model/`, а не в кэше Hugging Face.
- **AC-2.** Дано скачанная модель, когда загружается `RuG2P`, тогда
  `espeak-data` находится рядом с `ru_g2p.py` и фонетика работает.
- **AC-3.** Дано выбранный голос `dima`, когда качается репозиторий, тогда
  чужие чекпоинты и ONNX-файлы не скачиваются.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| В `model/` уже есть файлы | `snapshot_download` дополняет папку |
| Нет прав на запись в `model/` | Ошибка скачивания, код возврата 1 |
| Сеть недоступна при первом запуске | Ошибка загрузки модели |
| В кэше уже есть модель | Она не используется; нужна папка `model/` |

## Решения и альтернативы

- **Решение:** `local_dir=MODEL_DIR`.
  **Почему:** `espeak-data` должна лежать рядом с `ru_g2p.py`.
  **Альтернатива:** кэш Hugging Face.
  **Почему отвергнута:** симлинки на `blobs/` ломают поиск `espeak-data`.
- **Решение:** игнорировать ONNX и чужие чекпоинты.
  **Почему:** они не нужны для выбранного голоса и занимают место.

## Влияние

- `synthesizer.py` получил `MODEL_DIR` и `local_dir`.
- `.gitignore` исключает `model/`.
- Обратная совместимость: путь модели меняется, но CLI не меняется.
