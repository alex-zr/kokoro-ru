# 0009. Один аргумент: файл или папка

- **Статус:** Implemented
- **Дата:** 2026-11-12
- **Тип:** ретроспективная спека (восстановлена по коммиту)
- **Коммит:** `80a37f8` — `one arg support`
- **Связанные спеки:** 0007, 0008, 0001
- **Затрагиваемые файлы:** `main.py`, `tests/test_batch.py`, `README.md`

## Контекст и проблема

Флаг `--batch` требовал явно указывать, что аргумент — папка. Пользователю
приходилось помнить про режим, хотя тип пути уже однозначно говорит, что
делать. Кроме того, путь с пробелами нужно было брать в кавычки.

Нужно принимать один позиционный аргумент — файл или папку — и определять
режим автоматически.

## Цели и не-цели

**Цели:**

- один аргумент вместо «путь + --batch»;
- автоматически различать файл и папку;
- разрешить путь с пробелами без кавычек;
- сохранить `--batch` для совместимости;
- сохранить прежние проверки ошибок.

**Не-цели:**

- несколько файлов или папок за один запуск (кроме режима 0001);
- рекурсивный обход папки;
- интерактивный выбор файлов.

## Пользовательский сценарий

```bash
python main.py input/example.md
python main.py input
python main.py ~/Documents/my notes.md
python main.py ~/Documents/notes --voice masha --no-mp3
```

## Требования

- **FR-1.** Позиционные аргументы собираются в один путь через пробел и
  раскрывают `~`; кавычки не обязательны.
- **FR-2.** Без аргументов используется `input/example.md`.
- **FR-3.** Если путь — папка, включается пакетный режим: все `.md`/`.markdown`
  верхнего уровня.
- **FR-4.** Если путь — файл, обрабатывается только он.
- **FR-5.** Отсутствующий путь — ошибка с кодом 1.
- **FR-6.** Пустая папка — ошибка «нет Markdown-файлов», код 1.
- **FR-7.** `--batch` остаётся устаревшим флагом: требует папку, с файлом
  выдаёт ошибку.
- **FR-8.** `-o` запрещён, если аргумент — папка.
- **FR-9.** Режим определяется по `source.is_dir()`; прогресс и итог пачки
  работают как раньше.

## Критерии приёмки

- **AC-1.** Дано путь с пробелами, переданный несколькими аргументами, когда
  вызывается `input_path`, тогда части склеиваются через пробел.
- **AC-2.** Дано отсутствие аргументов, когда вызывается `input_path`, тогда
  возвращается `input/example.md`.
- **AC-3.** Дано папка с двумя `.md`, когда вызывается `resolve_sources`,
  тогда возвращаются оба файла.
- **AC-4.** Дано один `.md`, когда вызывается `resolve_sources`, тогда
  возвращается он сам.
- **AC-5.** Дано отсутствующий путь, когда вызывается `resolve_sources`,
  тогда возвращается ошибка «не найден».
- **AC-6.** Дано файл и `--batch`, когда вызывается `resolve_sources`, тогда
  возвращается ошибка «ожидает папку».
- **AC-7.** Дано папка и `-o`, когда запускается CLI, тогда печатается
  запрет и код 1.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| Путь с пробелами без кавычек | Склеивается в один путь |
| `~` в пути | Раскрывается в домашнюю папку |
| Нет аргументов | `input/example.md` |
| Папка без `.md` | Ошибка, код 1 |
| Файл с `--batch` | Ошибка, код 1 |
| Папка с `-o` | Запрет, код 1 |
| Несколько путей | Склеиваются в один (не поддерживается) |

## Решения и альтернативы

- **Решение:** `nargs="*"` и склейка через пробел.
  **Почему:** так работают пути с пробелами без кавычек.
  **Ограничение:** несколько независимых путей за запуск не поддерживаются.
- **Решение:** режим по `source.is_dir()`.
  **Почему:** тип пути однозначен, отдельный флаг не нужен.
- **Решение:** оставить `--batch` скрыто совместимым.
  **Почему:** старые команды не должны падать.

## Влияние
