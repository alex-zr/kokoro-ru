# 0005. MP3 по умолчанию и удаление промежуточного WAV

- **Статус:** Implemented
- **Дата:** 2026-11-11
- **Тип:** ретроспективная спека (восстановлена по двум коммитам)
- **Коммиты:** `d3acb64` — `fixed model download` (флаг),
  `49bb480` — `remove intermediate wav in mp3 mode`
- **Связанные спеки:** 0002, 0006, 0008
- **Затрагиваемые файлы:** `main.py`, `kokoro_tts/config.py`, `README.md`

## Контекст и проблема

Изначально результатом был `.wav`, а `.mp3` создавался только с флагом
`--mp3`. На практике пользователю нужен компактный `.mp3`, а промежуточный
`.wav` после конвертации только занимал место и путал в папке.

Нужно сделать `.mp3` основным результатом и не оставлять `.wav`, если
конвертация прошла успешно.

## Цели и не-цели

**Цели:**

- сохранять `.mp3` по умолчанию;
- дать способ получить только `.wav` через `--no-mp3`;
- сохранить совместимость со старым флагом `--mp3`;
- удалять промежуточный `.wav` после успешной конвертации;
- корректно вести себя без `ffmpeg`.

**Не-цели:**

- настройка битрейта и параметров кодека;
- другие аудиоформаты;
- пакетная обработка (спека 0007).

## Пользовательский сценарий

```bash
python main.py input/notes.md              # -> notes.mp3, notes.wav удалён
python main.py input/notes.md --no-mp3     # -> notes.wav, mp3 не создаётся
python main.py input/notes.md --mp3        # совместимость: mp3 и так по умолчанию
```

## Требования

- **FR-1.** По умолчанию после синтеза создаётся `.mp3`.
- **FR-2.** С `--no-mp3` создаётся только `.wav`, конвертация не запускается.
- **FR-3.** Старый флаг `--mp3` остаётся скрытым и не меняет поведение
  (mp3 уже включён по умолчанию).
- **FR-4.** Конвертация выполняется через `ffmpeg -y -loglevel error`.
- **FR-5.** После успешной конвертации промежуточный `.wav` удаляется.
- **FR-6.** Если `ffmpeg` не найден, печатается подсказка
  `brew install ffmpeg`, `.wav` сохраняется, команда не падает.
- **FR-7.** В сообщении «Готово» печатается длительность аудио и время синтеза;
  для mp3 дополнительно указано, что wav удалён.

## Критерии приёмки

- **AC-1.** Дано установленный `ffmpeg`, когда синтез завершён без флагов,
  тогда существует `.mp3`, а `.wav` отсутствует.
- **AC-2.** Дано `--no-mp3`, когда синтез завершён, тогда существует `.wav`,
  а `.mp3` отсутствует.
- **AC-3.** Дано `--mp3`, когда синтез завершён, тогда поведение совпадает с
  запуском без флага.
- **AC-4.** Дано отсутствие `ffmpeg`, когда синтез завершён, тогда `.wav`
  остаётся, печатается подсказка об установке.
- **AC-5.** Дано ошибка `ffmpeg`, когда конвертация не удалась, тогда
  исключение не скрывается, `.wav` не удаляется.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| Нет `ffmpeg` | Остаётся `.wav`, подсказка, успешный код |
| `ffmpeg` вернул ошибку | Исключение, `.wav` остаётся |
| `--no-mp3` и `--mp3` вместе | Побеждает последний разобранный флаг |
| Имя файла с точками | Меняется только расширение |

## Решения и альтернативы

- **Решение:** mp3 по умолчанию, `--no-mp3` для wav.
  **Почему:** mp3 — основной пользовательский результат, wav — технический.
- **Решение:** оставить скрытый `--mp3` для совместимости.
  **Почему:** старые команды и конфигурации не должны ломаться.
- **Решение:** удалять wav только после успешного `ffmpeg`.
  **Почему:** при ошибке пользователь не должен потерять результат.
