## Контекст и проблема

В синтезе показывается число обработанных предложений, а для папки отдельно
печатается номер текущего файла. Пользователь хочет видеть оба значения как
прогресс-бары.

## Цели и не-цели

**Цели:**

- Показывать бар текущего файла по завершённым предложениям.
- В пакетном режиме показывать бар общего хода по файлам.

**Не-цели:**

- Оценка оставшегося времени или общего объёма аудио.
- Новые зависимости и изменение синтеза.

## Пользовательский сценарий

```text
Файлы [██░░░░░░░░] 1/5 · Глава.md [████░░░░░░] 14/32 предложений
```

## Требования

- **FR-1.** Во время синтеза текущего файла отображается бар по предложениям
  и счётчик `готово/всего`.
- **FR-2.** В пакетном режиме отображается отдельный общий бар по файлам;
  файл считается завершённым после успеха или ошибки обработки.
- **FR-3.** В режиме одного файла общий бар не показывается. Для `--clean-only`
  сохраняется номер текущего файла и общий бар по завершении файлов.
- **FR-4.** Прогресс обновляется в одной перезаписываемой строке, итоговые
  сообщения печатаются с новой строки. Бар строится стандартной библиотекой.

## Критерии приёмки

- **AC-1.** При синтезе одного файла вывод содержит бар предложений и `done/total`.
- **AC-2.** При обработке папки строка синтеза содержит общий бар `файлы
  завершены/всего` и бар предложений текущего файла.
- **AC-3.** После каждого файла, включая файл с ошибкой, общий счётчик
  увеличивается ровно на один; итоговые сообщения не затираются баром.
- **AC-4.** В `--clean-only` нет бара предложений, а пакетный бар обновляется
  для каждого обработанного файла.

## Крайние случаи и ошибки

| Ситуация | Ожидаемое поведение |
|---|---|
| Синтезатор сообщил `total=0` | Бар не делит на ноль, показывает `0/0` |
| Ошибка чтения/синтеза файла | Общий бар считает файл завершённым, пачка идёт дальше |
| Одиночный файл | Только бар предложений |

## Решения и альтернативы

- **Решение:** общий бар измеряет число завершённых файлов, текущий бар —
  предложения текущего файла. **Почему:** эти счётчики имеют определённые
  единицы измерения. **Альтернатива:** единый процент пачки по предложениям;
  отвергнута, поскольку общее число предложений заранее не вычисляется.
