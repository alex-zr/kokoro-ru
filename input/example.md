# Как мы озвучиваем документы

Этот файл нужен, чтобы **проверить**, как *очищается* разметка перед озвучкой.
Ссылки вроде [документация Hugging Face](https://huggingface.co/zaakirio/kokoro-ru) читаются как обычный текст.

## Что умеет проект

- Убирает разметку и ссылки.
- Заменяет блоки кода короткой фразой.
- Делит длинный текст на предложения.

> Хорошая озвучка начинается с хорошо подготовленного текста.

## Пример кода

```python
print("Привет, мир!")
```
